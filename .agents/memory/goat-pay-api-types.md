## Rule
Use the exact field names from the generated OpenAPI types — they differ from what you'd guess:

- `Sale.customerName` (NOT `buyerName`)
- `Sale.customerEmail` (NOT `buyerEmail`)
- `Affiliate.totalSales` (NOT `sales`)
- `Affiliate.totalCommission` (NOT `commission`)
- `Affiliate.commissionRate` — the rate percentage
- `AffiliateStats.totalCommissionPaid` (NOT `totalCommissions`)
- `AffiliateStats.totalSalesGenerated` (NOT `pendingCommissions`)
- `WithdrawalInput` requires `pixKey: string` (mandatory, not optional)

**Why:** These are generated by Orval from the OpenAPI spec. Intuitive names don't match.

**How to apply:** Always grep the `.d.ts` file at `lib/api-client-react/dist/generated/api.schemas.d.ts` when adding new API fields rather than guessing.
