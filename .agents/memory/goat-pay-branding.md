## Rule
GOAT-PAY has **exclusive branding** — never include references to any competitor/platform.

**Banned names/logos:** Hotmart, EscalePay, Escalapay, Cakto, Kiwify, Eduzz, and any other payment platform.

**Why:** User explicitly requires 100% exclusive GOAT-PAY identity throughout the system.

**How to apply:**
- Replace any placeholder text with "GOAT-PAY" branding
- User display: "SKILL" / "Elite Member"  
- Logo: `/goat-logo.png` (served from `artifacts/goat-pay/public/`)
- Watermark: logo with opacity ~0.025 (dark) / ~0.04 (light), fixed bottom-right, z-index 0
- Neon colors: `#00e676` dark mode, `#00a84f` light mode
